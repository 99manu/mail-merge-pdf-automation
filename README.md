# Save Mail Merge To Individual PDFs tool (1-Click)

Welcome to the official repository for our **Mail Merge Series** on Tattvam Tutorials. This specific project covers the automation tool used to save individual merged pages as uniquely named PDF files.

### 📥 Practice Files Included:
**SaveMailMergeToIndividualPDFs.dotm** – The Add-in tool file.
**Student_ReportCard_Data.xlsx** – The practice spreadsheet carried over from Part 1.

📂 Installation Instructions

Open the file and follow these steps:

Step 1: Find your Word Startup folder
•	Open Microsoft Word.
•	Go to File → Options → Advanced.
•	Scroll down to the General section and click File Locations.
•	Click on Startup, then click Modify.
•	Copy the folder path shown at the top of the window.

Step 2: Save the file
•	Open your computer's File Explorer, paste the folder path you copied in the last step into the address bar, and press Enter. You will be taken directly to the Startup folder.
•	Copy and paste the “SaveMailMergeToIndividualPDFs.dotm” file right inside it.
Note: The first time you start Word after installing this tool, you may see an “Add-in Alert” message saying that Word detected an issue or that the add-in might slow down startup. This is standard behavior for Word add-ins placed in the Startup folder. Simply click “Don’t ask me again” and continue. The tool is completely safe, and the message will not appear again.

Step 3: Verify
•	Close Word completely and open it again.
•	Go to the Mailings tab at the top menu: Mailings → Mail Merge PDF → Save Individual PDFs.
•	You will see your new button ready to use!
